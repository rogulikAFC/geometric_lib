# Библиотека для нахождения периметров и площадей геометрических фигур

## Общее описание решения
В репозитории собраны простые функции на Python для подсчета площади и периметра базовых фигур: круга, прямоугольника, квадрата и треугольника.

Каждая фигура вынесена в отдельный файл. В каждом файле есть две функции:
- `area(...)` — считает площадь;
- `perimeter(...)` — считает периметр.

## Поддерживаемые фигуры
* Круг (`circle.py`)
* Прямоугольник (`rectangle.py`)
* Квадрат (`square.py`)
* Треугольник (`triangle.py`)

---

## Описание функций

### Круг (`circle.py`)

#### `area(r: float) -> float`
* Принимает значение радиуса r круга, возвращает площадь круга.
  * **Параметры**:
    * `r` (float): длина радиуса круга
  * **Возвращаемое значение**:
    * `area` (float): площадь круга
  * **Пример вызова**:
    ```python
    res = circle.area(5.0)
    print(res)  # Вывод: 78.53981633974483
    ```

#### `perimeter(r: float) -> float`
* Принимает значение радиуса r круга, возвращается периметр круга.
  * **Параметры**:
    * `r` (float): длина радиуса круга
  * **Возвращаемое значение**:
    * `perimeter` (float): периметр круга
  * **Пример вызова**:
    ```python
    res = circle.perimeter(5.0)
    print(res)  # Вывод: 31.41592653589793
    ```

---

### Прямоугольник (`rectangle.py`)

#### `area(a: float, b: float) -> float`
* Принимает значение длин сторон прямоугольника a и b, возвращает площадь прямоугольника
  * **Параметры**:
    * `a` (float): длина 1 стороны прямоугольника
    * `b` (float): длина 2 стороны прямоугольника
  * **Возвращаемое значение**:
    * `area` (float): площадь прямоугольника
  * **Пример вызова**:
    ```python
    res = rectangle.area(4.0, 5.0)
    print(res)  # Вывод: 20.0
    ```

#### `perimeter(a: float, b: float) -> float`
* Принимает значение длин сторон прямоугольника a и b, возвращает периметр прямоугольника
  * **Параметры**:
    * `a` (float): длина 1 стороны прямоугольника
    * `b` (float): длина 2 стороны прямоугольника
  * **Возвращаемое значение**:
    * `perimeter` (float): периметр прямоугольника
  * **Пример вызова**:
    ```python
    res = rectangle.perimeter(4.0, 5.0)
    print(res)  # Вывод: 18.0
    ```

### Треугольник (`triangle.py`)

#### `area(a: float, h: float) -> float`
* Возвращает площадь треугольника.
  * **Параметры**:
    * `a` (float): длина основания
    * `h` (float): длина высоты
  * **Возвращаемое значение**:
    * `area` (float): площадь треугольника
  * **Пример вызова**:
    ```python
    res = triangle.area(6.0, 3.0)
    print(res)  # Вывод: 9.0
    ```

#### `perimeter(a: float, b: float, c: float) -> float`
* Возвращает периметр треугольника.
  * **Параметры**:
    * `a` (float): длина 1 стороны
    * `b` (float): длина 2 стороны
    * `c` (float): длина 3 стороны
  * **Возвращаемое значение**:
    * `perimeter` (float): периметр треугольника
  * **Пример вызова**:
    ```python
    res = triangle.perimeter(3.0, 4.0, 5.0)
    print(res)  # Вывод: 12.0
    ```
